# Comparação de Números

Exercício de HTML e JavaScript: um formulário que verifica se o número B é maior que o número A.

## Funcionalidades

- Formulário com dois campos numéricos
- Mensagem de sucesso (verde) quando B é maior que A
- Mensagem de erro (vermelha) quando não é

## Como executar

Abra o arquivo `index.html` no navegador.

## Tecnologias

- HTML5
- CSS3
- JavaScript
